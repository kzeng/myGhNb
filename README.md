# My GH Notebook

![GH Notebook Logo](docs/gh-notebook-logo.png)

Personal Android Markdown publishing tool for `kzeng/kzeng.github.io`.

## Current MVP

- Material 3 visual direction
- GitHub + Notebook vector product logo
- Android 12 splash logo
- Local draft storage for offline writing
- Markdown editor and article reader
- GitHub `clash` branch list/publish client
- imgchr web upload entry point and clipboard insertion
- About page: `Author: Zengkai001@gmail.com`, `Version: 0.0.1`

## Local setup

This project requires Android Studio with JDK 17 and Android SDK 35. Configure a GitHub fine-grained token in the app settings implementation before publishing. Do not put passwords or tokens in source code.
